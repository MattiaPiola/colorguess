# colorguess

Simple lightweight webapp to train color guessing.

## Modes

1. **Color Guess**
   - Recreate the target color using RGB, CMYK or HSL values.
   - Supports infinite mode or fixed number of rounds.
   - Target can stay visible or be hidden after configurable seconds.
2. **Color Harmony**
   - Start from a base color and match one or more harmony target colors.
   - Harmony kinds: analogous, complementary, split complementary, triad, bad harmony.

Both modes provide distance-based feedback and score.

## Run

Open `index.html` from the project root in a browser.
